# Clube do Ritmo

O Clube do Ritmo é um site sobre um clube fictício de música. Ele apresenta instrumentos, exercícios de ritmo, oficinas, uma agenda de encontros e um formulário de demonstração de inscrição.

O projeto foi desenvolvido para praticar os conteúdos de HTML das aulas de Desenvolvimento Front-End para Web. Sua proposta é organizar várias páginas interligadas, utilizando somente os recursos apresentados nos materiais da disciplina.

## O que foi desenvolvido

A versão atual possui **12 páginas HTML**, todas com menu completo, estrutura semântica e meta tags.

| Página | Conteúdo |
| --- | --- |
| `index.html` | Apresentação do clube e sugestão de percurso pelo site. |
| `sobre.html` | Proposta do clube e combinados para participar das atividades. |
| `instrumentos.html` | Apresentação do violão, teclado e pandeiro. |
| `ritmos.html` | Exercícios de contagem, palmas e pausas. |
| `oficinas.html` | Descrição das oficinas e exemplos de `progress` e `meter`. |
| `agenda.html` | Programação fictícia organizada em tabela. |
| `galeria.html` | Imagens dos exercícios com descrições e legendas. |
| `audio.html` | Áudio local para praticar uma sequência de quatro tempos. |
| `video.html` | Vídeo local com a contagem visual do exercício. |
| `inscricao.html` | Formulário com os campos básicos e avançados. |
| `duvidas.html` | Perguntas frequentes com respostas que abrem e fecham. |
| `conclusao.html` | Explicação do formulário e destino após concluir o preenchimento. |

As mídias incluem três imagens PNG, um áudio MP3 e um vídeo MP4. O áudio e o vídeo foram criados para o exercício musical e têm aproximadamente 10 segundos. Os arquivos ficam no próprio projeto e podem ser utilizados sem internet.
